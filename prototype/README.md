# AI 导演工作台功能原型

本目录是 V2.1 首期范围的设计评审材料，不是生产应用。

Figma 文件：https://www.figma.com/design/ppqfoOzolnNGYAdmT9XIjp

主设计包含 66 个功能页面及关键状态、逐页交互说明和可点击导航。素材采用明确标注的构图示意。字段为示意，真实表单、文件操作、执行器、付费服务和本地打包均为示意。

本地打开 `index.html` 可浏览同一页面清单；字段与正文可以保存到当前浏览器会话。页签和筛选为状态示意，主按钮演示页面跳转，不执行对应真实业务。

- `screens.json`：页面字段、说明、异常规则和跳转目标。
- `screens.js`：供离线页面加载的数据。
- `prototype.js` 与 `prototype.css`：本地评审界面。

范围以 2026-11-06 的 V2.1 实施计划为基准；代码目录与项目名采用 AI Director Workbench。现行补充含 47–54「从参考片写剧本」，演示拉片、节拍取舍、改编独审和剧本采用。

55–66 演示镜头取舍、构图设计、同镜比较、原创镜和采用前的局部复核。构图由 shot-design.js 在本地绘制，全部为本原型的原创示意。
