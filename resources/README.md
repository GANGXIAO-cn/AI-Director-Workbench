## 其他本机依赖

- Codex、Claude Code、Google CLI 由各自的本机程序执行并读取原生登录状态。
- 启用 OpenAI 图像 MCP 的实际生成与回查依赖本机安装的图像服务及其独立凭证。
- PUGGY ROOM 系列模板另外引用该系列自己的素材、选题台账和历史作品。普通项目不需要这些私有文件。已另存的项目使用各自的冻结资料。
- 单独测试 H3 下游导入时可使用 H3 Studio 仓库，日常工作台导出使用随附打包器。
