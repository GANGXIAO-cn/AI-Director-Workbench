# 提示词对照

本遍只核对最终提示词是否忠实翻译、引用并组装已采用的剧本、表演、镜头、分段、素材用途和导演决定。上游是依据，不是本遍重新审查的对象。

## 检查范围

- 本段动作、对白、机位、时间窗、声音和结束状态是否遗漏、错译或擅自改变。
- 图片标签、上传顺序与采用绑定一致；身份、环境、外观、首尾帧各承担已确定的用途，不暗中升级用途。
- 固定信息是否按本轮契约装配；内部审核记录不混入生成正文。
- 与相邻段的文字状态是否按采用方案接续，不重新判断方案的摄影优劣或动作可行性。
- 本段是否违背明确的项目设定和适用导演决定。不要求每段重复填写整套设定核对表。

## 不重复审查

不重新选择图片，不以图上附带物要求新增剧情道具编号。身份图不用证明服装与动作，环境图不用证明机器运行或声音，外观图不用演出接触。已接受的限制保留，不能因未重新拍摄或换图而再次否决。

不重新审故事因果、表演设计、镜头时间是否足够；只检查提示词有没有偏离已采用设计。若发现新出现的输入矛盾，引用双方原句、指出责任阶段和具体变化，不能仅凭旧依据要求重做上游。

尚未生成的视频、轴线效果、触达距离、真实速度、表情运动和声画同步只记录未测，不作为提示词 issues 或 uncertain 的依据。无实际表达错误时 pass；不把静态审查称为视频效果通过。

制作补充按已确认事实继承。观察与问题位置遵守本次收稿契约，不另造编号规范。修订只覆盖改动段及实际受影响的接点。
