## 从现行制作基准读取标准

- 制作基准/角色外观标准.json：video_zh及video_zh_version固定角色短块；MILO/LEO同框加pair_rules的短块。普通家猫大小、胖瘦、后腿直立、前爪拿东西和毛茸茸猫爪不可临时省略。详细en用于绘图。
- 制作基准/视频提示词标准.json：visual_style、motion、reference_use、cats_silent、frame_text，grid另用grid_reference。按本段适用项完整引用一次，不临时概括，不为字数删掉风格/速度/文字/声音限制。
- 每段登记prompt_format: readable_v3；从config.json指定的现行制作基准直接读取角色、视频和声音标准，检查TXT在对应位置完整引用适用块。

固定块本身不写图片序号。flex用“实际标签：角色video_zh原文”；同框短块仅一次。后文直接用角色名，不强制再提图片标签。临时服装、湿毛、姿势另写，不改固定块；固定图的表情不锁全段。

```text
图片1：<从文件完整读取的角色video_zh>

<适用的短同框块及reference_use原文，各一次。>

<visual_style与motion原文，各一次；对整段视频生效。>
【开场】
<本段具体时段/光线、拍摄来源、布局、进出/运动方向、角色位置、持物数量和装置初态。>
【镜头与动作】
00:00-<数字结束时间码>
起镜，<起始机位、动作、结果。后续每个平铺区间一行时间码，正文用“同镜延续，”或“切镜，”开头。>
<各时间段连续覆盖生成时长，最后一段明确结束与接续。>
【声音与文字】

```

模板的声音栏示范无背景配乐的写法；声源描述按本段实际内容填写，不照搬其他段。若已确定需要生成背景配乐，将该行改为 `non_diegetic_music: <实际配乐描述>`，不同时保留 N/A。模板占位说明不进入正式TXT。

【基本设定】描述整段生效的画面风格、材质光影基准和动作速度/重量/接触规则；【开场】只写本段起始的具体环境、人物位置、持物与装置状态。不能把通用规则放进开场，也不能在两栏重复。镜头中需要的具体灯光或特殊动作另按实际叙事写清。

purpose/shots/exclusions留在清单与网页核对，不直拼TXT。参考职责用简短、具体的画面语言；审核结论、未测试说明、制作理由、内部商品编号不进入模型正文。真实输入冲突先修图、派生或替换，不能用长串排除句掩盖。缺素材时保留待办并继续授权制作，不把草稿当完整交付。带角色的 flex 状态图只用本段开场图；后态不能提前传。实际选图先消除状态冲突，不能指望“仅取外观／不是首尾帧”排除图中的角色、地点和结果。各媒体按清单从1编号，实际入口的at标签须先核实并全段统一。每段1—9张实际图片，视频/音频限额按入口核实；未存在的素材不列成正式输入。

## 平铺时间段

flex 的【镜头与动作】与 grid 的“镜头描述：”同规则。每个生成段从零计时，各行时间码按 `00:00-00:02` 格式独占一行。其后首个非空行的第一个词必须为“起镜”“同镜延续”或“切镜”，紧接中文逗号与自然摄影、动作描述。联合表写同词，不带逗号。开头用起镜，后续按相机是否真实切换选择另两词。

```text
00:00-00:02
起镜，固定近景对准桌边，一只手把杯子推向画面右侧。
00:02-00:05
同镜延续，机位仍固定，接杯的手从右侧入画，托稳杯底。
00:05-00:07
切镜，从桌对侧拍接杯者的脸。她看见杯底裂缝，皱眉收住手。
```

以上三段、两镜、一次切镜。禁止外层总区间再套正式区间或“阶段1｜…”子行。程序在每个平铺段的正文中单独计数：出现两个及以上秒数区间（如“0–2 秒推杯，2–4 秒接杯”）即阻断，换行仍累计；不同段不累计。单个动作时间点“约第2秒接住”和物理时长“停留约2秒”允许；单个正文区间若实际上承担独立观看任务，人工要求重分时间段。

## 摄影、动作和表情用正常中文写全

每镜先写摄影机相对主体的位置、朝向、高低和景别；固定则明说，移动则写起点、类型/方向、幅度或地标终点、完成时间和停后画面。沿用方案中已确定的设计值。推进/变焦、平移/摇镜分清；硬切不是连续运镜，不让机位穿墙。一个主运镜目的，组合移动按顺序交代。轴线与出入口在本段可理解，不能用“同侧”借用未提供的上一段机位。

每段独立说明起始状态和必要空间关系，对象首次出现用明确名称，不能用未定义的“柄”“同侧”借用上段信息。谁做什么、先后与同时关系、支撑/接触/力度及可见结果写成完整句，不把字段和设计理由串起来。正常速度与短动作利落落实到实际表演；不均匀慢演、不用空等填时长。特殊慢动作应回到方案明确选择并处理与默认速度要求的冲突。

每段有角色表演的提示词均须写出与主要动作配合的表情。区分**动作正在发生时的表情**与**事件造成的情绪变化**：用力、瞄准、试探、忍耐、逞强或装镇定时，表情应与身体动作同步；不能只补事后的惊讶。关键情绪写事件前注意力→动作中的表情/姿态→触发结果→可见变化，按情绪选部位，不每次列全。两猫反应有区别，给足辨认窗口，读清即走。景别与遮挡须支持看清：远景用大动作，手爪特写不同时承担脸部反应。驾驶时不长时间闭眼/回头，双爪控把时不另加摸脸。不能只增加“得意/震惊”等形容词来代替表演，也不逐镜强制变脸；这表示情绪可连续保持，不表示可以省掉主要动作的表情。

例如用力拉渔竿：MILO把竿柄紧抱胸前，肩背绷起向后拉，同时眯紧双眼、耳朵向后压、嘴闭紧；鱼线突然反扯，他眼睛骤然睁大，双耳后收，身体随竿向前一顿。用力状态和失控反应各有动作依据，按实际段落时长与景别取舍；这是写法示例，不自动改写既有剧情、站位或支撑。不能只写“眼睛盯线”“下巴抬起”便算完成拉竿时的表情设计。

逐段检查主要表演动作是否都得到相应表情支持，而非检索是否出现一个表情词。关键动作的注意对象及转移沿用镜头方案，正面景别不默认看镜头；表情、头部朝向与眼睛注视目标要相容。具体视线与调度规则见camera-rhythm.md“注意力与视线”。纯场景/物件段可注明无角色表演；接触特写可把脸部表演放到本段前后可见角色的镜头内，远景用头部和身体姿态承担情绪。不得为了补表情给每镜加同一种惊讶、延长动作或增加与原故事无关的反应。

时间安排遵循[camera-rhythm.md](camera-rhythm.md#镜头时间与生成分段)：各独立观看窗口平铺，连续镜号可对应多个区间。通读时只看本段TXT与输入，能复述谁在哪里、做什么、怎样切镜和怎样结束；无法复述则回到方案重写受影响段落，不能靠末尾追加补丁句。

先在本段写清人物和物件分别在哪里、谁先动、另一人看见什么而改招，以及镜头停在哪个可见结果。两人换交通工具或道具易混淆时，在动作句里继续用能辨认的名字。画面中的记号要写在它所依附的实物上，例如写“灰衣人带着果箱乘列车远去，车门边还能看见他皮包上的白蹄印”。从写好的正文摘一句短语填入联合表的“TXT定位短句”，再核对时间。脚本可装配时间码、固定标准及已审正文；逐字拼接制作表的机位栏、动作栏和声音栏，需要退回撰写。

## 声音、接续与画面文字

每个独立段写本段起止声音与必要环境底，不因总方案写了夜间就漏掉本段环境声。相同物件声音身份连续，距离与拍摄机位匹配；发动机熄火后不再有怠速，无摩托场景不带入摩托声。动作声自然附在动作后即可，不为每镜塞满声音字段。

猫不说人话；人类对白只在实际需要时写固定英语声线、说话者和窗口，词数/语速预算在制作方案核算。音乐、画内演奏和环境声区分，不借配乐掩盖失败。

沿用本集已确定的声音方案。无背景配乐的每个独立生成段，在声音栏单独写一行 `non_diegetic_music: N/A`；环境声、动作声和必要对白仍按实际声源与起止描述。该行是H3提示词指南中的文本标记，不是新增接口参数，也不保证实际生成无配乐；有样片时仍须试听。无背景配乐不等于完全静音，不将 `overall_soundscape` 设为 N/A 来取消环境声。

场景内乐器演奏、收音机等属于画内音乐，按剧情描述；不因无背景配乐而取消。后期BGM安排留在制作方案、发布包和精剪交接中，不作为要求模型生成配乐的内容写入TXT。已明确需要生成背景配乐的段落，按实际方案描述，不填写 N/A。

本段输入/声音是否共享、接续依赖、后期试听状态留在制作方案/使用说明，模型TXT只写当前应该生成什么。各段仍自包含身份、空间、持物、声场与接续状态。保留完整frame_text，CAM/REC等如需后期叠加列在方案；比例/分辨率/总时长在复制区外，剧情数字时间码仍在正文。

## grid

grid仍仅上传本段九宫格，不额外输入原角色图。保留原标题：分镜参考、主角、环境、摘要与衔接、镜头描述、运镜边界、声音与音乐、画面文字。reference_use和grid_reference在分镜参考区；角色与同框短块在主角区；visual_style/motion及本段光线在环境区；cats_silent在声音区；frame_text在画面文字区。九格是关键状态，不是九次硬切，生成单画面。

grid的“声音与音乐”栏同样逐段填写配乐状态：无背景配乐时单独写一行 `non_diegetic_music: N/A`，保留实际环境声、动作声、对白及剧情需要的画内音乐。局部修订同步受影响段及汇总提示词和网页复制内容。
