# 05 剧本

本文件只用于从上游成果写剧本。导演定稿导入时不适用。

与对标来源的取舍：不存在按院线、电影节、竖屏短剧选择排版格式的问题，输出结构以本次契约为准；写法按本方法，只写观众看得见的行动。

## 方法

### 各稿各管什么

梗概、角色、规则、分场维护目标、因果、规则、结构和结局；剧本把这些内容展开为观众可见的行动、表演与阶段变化，不另立一套故事；剧本同时维护拍摄段落、预算与起止状态；镜头方案在这些段内维护机位、动作窗口、接续和素材需求。冲突回源处理，不靠下游选一边掩盖。

| 上游 | 本稿落实 |
|---|---|
| 梗概、因果核对 | 按观众看到的顺序展开可见行动与反应，让角色选择的原因在画面里可读 |
| 时间线 | 继承时段、人物位置与在场情况、状态变化；在段首或段尾说明跳跃与省略，区分故事经过时间和视频片长 |
| 规则与关键道具 | 继承关键道具外观、来源、触发与不触发条件及模式切换 |

### 每场写清什么

观众可见的行动与关键表演；主角的选择或办法；阻碍或他人回应（按需）；新局面；预期、看点与回收；必要声音。行内写因果和先后。

- 同一结构里的变化要具体：改控制方式、揭开秘密、改变规则、重用前段后果等。换物件、增大份量或重复失败，只有改变条件和关系时才增加发展。
- 对手的有效反制迫使下一步改招；不必把每一场硬套成攻防。
- 准备、赶路、拿放、复位默认切到结果，状态与省略写清。关键因果或过程看点才保留完整展示。必要的来源、触发条件及回收不能因省操作而消失。

### 反查

- 开场进入本集特有的异常，让观众想知道结果。
- 看点写清预期、实际反差和谁知道什么；不以“机智、升级、有趣”代替事件。
- 对手出现时能改变局面；安静拍有识破、预期或控制权变化，不必每拍都是奇观。
- 高潮回应前提与目标，最后有效落点后结束。
- 删一场故事几乎不变？压缩或重写。换掉主角也不用改？加强选择。新观众不读简介能看懂目标、阻碍与结果？补最少可见信息。

### 不在本稿另加剧情

可以补充不改变故事含义的动作力度、空间布置和普通背景细节。新增关键道具、改触发条件、改变胜负或依靠新行为修补因果，属于故事改动，应先回上游修改。

展开时发现具体因果冲突，指出位置及影响；涉及目标、规则或结果的修改回上游处理。

先展开可见行动，再考虑预算。预算无法支持已确认的故事时，先调整表演和分段，仍不足再回上游修改，不自行加剧情或用操作填充。

## 同次写作完成拍摄拆段

完整场次可长于15秒，顶层 shootingSegments 按动作结果和对白语义拆为当前入口允许的拍摄段落（当前 H3 打包为5–15秒整秒）。每段写稳定编号、所属场次、顺序、预计时长、动作与对白、必要声音、起止状态。分镜沿用这些段号和预算；不机械平均截秒，不新增确认点或审核调用。

notes 只记录实际未解决事项，没有就留空；不附“严格依据、已经核验、符合规格”等自证段落。完整场次与拍摄段落之外不额外写审查报告。
