# 工作台故事稿字段与交接

故事梗概、本集角色表和交接说明随稿交付。以下字段分别保存，可按原字段修改、对照或组合。

| 字段 | 交付内容 |
|---|---|
| synopsis | 故事梗概。让第一次读到本稿的人按发生顺序看懂动机、选择、行动和结果。 |
| cast | 本集角色表。Markdown 表头至少包含「角色ID」「身份与作用」「独立身份基准」。角色 ID 以小写英文字母开头，可含数字和连字符，各行唯一。独立身份基准填「需要」或「不需要」。 |
| handoff | 交接说明。写目标时长、用户保留项、制作风险和待验证事项。没有特殊限制可写「无」。 |

按当前故事的复杂度选用以下辅助。已经写在梗概里的内容无需为填表再抄一遍。

| 字段 | 开发辅助 |
|---|---|
| spine | 故事脊、开场钩子、回收和目标时长。 |
| timeline | 发生时间、时间压力、阶段间隔、角色位置与状态变化。 |
| props | 规则与道具表。写来源、外观、作用与不作用、首次出现及后续变化。 |
| causes | 因果核对表。写核心障碍、简单办法为何行不通、选择与可见理由、行动结果和下一步。 |
| notes | 上述字段以外的开发说明。 |
| adaptation | 有参考包改编任务时，按本次提供的参考包和改编数据要求填写。 |

从想法开工时，第一稿可追溯到用户输入。导入故事或剧本时保留用户明确的前提、人物和原文来源，完成故事独审后再采用。连续集按本次提供的前集遗留事实交接。局部修订只返回需要变动的字段。
