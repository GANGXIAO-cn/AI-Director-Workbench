# short-film@v3 制作方法迁移记录

本版增加 17 个通用选段与 7 个 PUGGY 选段。编排覆盖选题三问、近期差异、故事交接、剧情阶段与分段预算、镜头时序、空间锁定、实际输入、连续集制作及精剪交接。项目专属案例按项目配置装入。选题池和连续故事页可展开对应原文。每份选段的原文件、提交、行号、原文件指纹和安装后指纹均在[版本清单](manifest.json)。

覆盖清单共 111 个源文件、294 个标题范围。136 个标题范围含选段，另有逐字节保存的项目文件，合计可对上 163 个范围。109 个范围的全部非空行可按原样在选段或项目副本中找到。原句被改写、只选取部分行或有意转成程序行为的范围，单独保留去向和选取行。小节中的品牌替换、改写及未覆盖处仍需继续对照。[逐文件覆盖与精确行数](../../../修复验证_20261108/v3_迁移源文件与小节覆盖.json)

空白项目和 PUGGY 项目分别通过故事、故事独审、剧本、方案、提示词、冷读、对照、发布八个实际装配入口。校验比较了清单次序与实际文件字节。两项目的冷读输入均为 425 字节文本加一张图片。其他需要专属方法的阶段在空白项目中明确说明该项未提供。记录中的文本字节数不等于模型 token 数。[两类项目运行输入](../../../修复验证_20261108/v3_两类项目运行输入.json)

剧本可保存拟生成段、观看作用、保留过程、可省操作和时长初估。采用制作方案后，工作台按镜号、来源场号和毫秒值复算分段预算。每个试验包只汇总所选段，并保留其在整集中的起点。用已归档的“站台雨伞”原始回包离线复算，8 段共 71 秒，32 个镜头均找到原句。[分段结果](../../../修复验证_20261108/站台雨伞_分段时长离线复算.json)

六个原检查脚本共 152 个直接位置。82 个已有制作或交付检查样本，53 个在历史导入路径核对，5 个在原格式角色页上核对。1 个针对补选区渲染器返回重复 ID 的异常，使用替换测试渲染结果的方式触发。11 个仅在原技能收到外部成片时触发，按工作台范围决定单列。对应代码位置、样本、诊断及适用边界见[检查对照](检查对照.json)。V4 的原测试逐例迁移和新旧制作流程等价仍需单列验收。

角色页可从已采用故事读取角色及其身份要求。制作人员可为本集登记独立身份原图、外观短描述，以及逐段实际出镜的图、格位和观察。登记基准后，生成段须确认身份或明确未出镜。第二遍审查记录所用基准，实际上传区按本段提示词中引用的文件出包。试验包只展示所选范围。见[身份原图与分段送审样本](../../../修复验证_20261108/本集身份基准与分段送审核对.json)和[角色页](../../../修复验证_20261108/11_本集角色设定与分段绑定.png)。

原技能 tests 目录的 15 个文件包含 174 个声明的测试方法。已有 111 个方法在固定版本原检查器和工作台副本上执行同组原断言。场景对照图覆盖每页重复锁定图、按声明筛选角色、身份与服装参考分栏。画幅新增 6 个用例，将原清单入口的画幅断言与工作台历史回执上的独立检查对照。提示词审查新增 5 个原例，另在 28 集声明适用格式的 268 段中核对了 286 条提示的原句和位置。[历史逐段结果](../../../修复验证_20261108/历史集提示词通读线索逐项对照.json)。其余 63 个仍需处理，其中 4 个涉及外部成片的显示比例和时长。场景部分核对采用输出、当前锁定图、请求号及实际输入文件的指纹，并按项目配置核对固定住宅场景的复用库 ID 和版本。[原测试与执行入口](../../../修复验证_20261108/原技能测试用例迁移.json)

### 源小节换行后的同步与回放

同步工具读取清单里的源提交。可用 `methods/tools/source_impact.py MANIFEST REPO ROOT TARGET` 查看变动的小节、使用阶段以及随前文移动的行范围。冻结新包时，`freeze_sections.py --ref short-film@vN --source-root ROOT --pins PINS.json` 将已审选段从基线提交映射到目标提交。遇到跨越选段的替换或恰在边界新增的语句，工具指出具体位置。通过 `--reviewed-ranges FILE` 传入以小节名称为键、含目标 `commit`、源 `path` 和新 `lines` 的 JSON，即可确定这些句子的归属。写入完整后，新版本才进入可选列表。

在“技能包与版本”选择项目和候选版本，可查看实际送入各阶段的正文差异、选段位置和装入顺序。采用版本对新开工集生效。“任务记录与详情”可展开某次运行冻结的方法正文、源提交和输入文件指纹。V6 使用本地技能的隔离克隆实改小节，在临时分支构建样本 v4，并回读采用前后的三次运行。[V6 实测记录](../../../修复验证_20261108/V6_方法小节改动与新旧集回放.json)
